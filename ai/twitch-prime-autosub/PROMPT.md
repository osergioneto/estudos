# Projeto: Auto Twitch Sub

Este documento é a fonte da verdade para o desenvolvimento da extensão de Chrome "Auto Twitch Sub".

## 1. Objetivo Principal

Criar uma extensão para o Google Chrome que renova automaticamente a inscrição (sub) de um canal específico da Twitch usando o sub gratuito mensal do Amazon Prime.
